Risks

⚠️ Challenges & Delays

Data unification

Users live in DB, Zoho, events & social with no shared key.

Legacy modules

Some sectors weren't built to talk to each other.

Privacy & consent

Tracking cross-sector activity needs clear user consent.

Team bandwidth

Parallel work across six live products.

Mitigation

✅ Suggested Solutions

One identity key

Phone/email as the universal user ID across all systems.

Bridge, don't rebuild

Shared internal API layer over existing modules.

Consent-first design

Clear opt-in; per-user data controls in the profile.

Phased rollout

Ship sector by sector; each bridge adds value alone.
